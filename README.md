## 📌 О проекте

**Лабанов** — это аркадная 2D-игра, написанная на Pygame. Игрок управляет героем,
который должен добраться до сокровища, обходя стены и избегая монстра.
Игра сопровождается фоновой музыкой и звуковыми эффектами победы и поражения.

### 🎯 Цель
Доведи героя до **сокровища** `treasure.png`, не задев монстра и стены.

### ⌨️ Управление

| Клавиша | Действие |
|---|---|
| `W` | Движение вверх |
| `S` | Движение вниз |
| `A` | Движение влево |
| `D` | Движение вправо |

### 🏆 Условия

| Событие | Результат |
|---|---|
| Достиг сокровища | ✅ **"You Win"** + звук победы |
| Задел монстра | ❌ **"You Lose, Try Hard"** + звук поражения |
| Задел стену | ❌ **"You Lose, Try Hard"** + звук поражения |

## 👾 Игровые объекты

### 🧍 Герой (`hero.png`)
- Управляется игроком через клавиши `WASD`
- Ограничен границами окна `(5–645 по X, 5–445 по Y)`
- Скорость: **5 пикселей/кадр**

### 🤖 Монстр (`cyborg.png`)
- Движется **вертикально** (вверх-вниз) автономно
- Патрулирует между `Y=20` и `Y=350`
- Скорость: **5 пикселей/кадр**

### 💰 Сокровище (`treasure.png`)
- Статичный объект — цель игрока
- Расположен в правой части карты

## 🛠️ Технологии

| Технология | Применение |
|---|---|
| **Python 3.x** | Язык разработки |
| **Pygame** | Игровой движок: рендер, события, звук |
| `pygame.display` | Создание окна `700×500` |
| `pygame.event` | Обработка ввода и выхода |

| `pygame.time.Clock` | Ограничение FPS до **60** |
| `dataclasses.dataclass` | Структуры `Sprite` и `Wall` |

## 🗂️ Архитектура кода

### `@dataclass Sprite`
Универсальный класс для всех спрайтов (герой, монстр, сокровище):
- `draw()` — отрисовка спрайта на экране
- `update_p2()` — обработка WASD-ввода с проверкой границ
- `monster_move(y_min, y_max)` — автономное вертикальное патрулирование

### `@dataclass Wall`
Класс стены на основе `pygame.Rect`:
- `draw_wall()` — отрисовка прямоугольной стены заданного цвета
